# Бесплатные Telegram-инструменты

Восемь готовых режимов: поиск групп, каналов и ботов, проверка имён в каталоге, объявления, небольшой срез покупательских запросов, поиск по сохранённым постам и выгрузка публичных постов канала.

Результат — JSON и CSV. Аккаунт Apify, аккаунт Telegram, токен бота и ключ API не нужны.

## Запуск на своём компьютере

Нужен Python 3.10 или новее. Дополнительных библиотек нет.

```bash
git clone https://github.com/JustJuice55/tgden-api.git
cd tgden-api
python3 -m tgden_tools groups --query python --limit 10 --output output
python3 -m tgden_tools channel-posts --username telegram --limit 5 --output posts
```

Можно скачать `tgden-tools.pyz` из выпуска и запускать его без клонирования:

```bash
python3 tgden-tools.pyz groups --query python --limit 10 --output output
```

## Бесплатный запуск через GitHub

1. Сделать [Fork репозитория](https://github.com/JustJuice55/tgden-api/fork).
2. Открыть **Actions** и включить задания, если GitHub попросит.
3. Выбрать **Run Telegram Tool → Run workflow**.
4. Указать инструмент, запрос или имя канала и число результатов.
5. В завершённом запуске скачать архив из **Artifacts**.

В архиве — `result.json`, `result.csv` и `metadata.json`. Для этого способа нужен бесплатный аккаунт GitHub. Стандартный Linux-запуск в публичном репозитории бесплатный по правилам GitHub; ограничения платформы и хранения файлов сохраняются. Файлы задания хранятся один день.

Публичное задание может показывать запрос, логи и результат другим людям. Для запросов, которые не хочется публиковать, используйте локальный запуск.

## Что умеет бесплатная версия

| Команда | Результат |
| --- | --- |
| `groups` | Группы по ключевому слову, до 50 результатов |
| `channels` | Каналы по ключевому слову, до 50 результатов |
| `bots` | Боты по названию задачи, до 50 результатов |
| `lookup` | Точные совпадения для списка до 10 публичных имён |
| `classifieds` | Метаданные объявлений, до 50 строк |
| `buyer-preview` | Маскированный публичный срез просьб покупателей, до 10 строк |
| `post-search` | Совпадения в сохранённых постах каналов, до 50 строк |
| `channel-posts` | Посты из текущего публичного превью канала |

Поиск групп, каналов и ботов идёт по каталогу TGDen. Смысловой поиск партнёрской версии и полная история Telegram в пакет не входят. Проверка имени в каталоге не доказывает, что имя доступно для регистрации или бот сейчас отвечает.

`channel-posts` читает публичную страницу Telegram напрямую. Закрытые группы и ссылки-приглашения не поддерживаются. `buyer-preview` сохраняет ограничения уже открытого превью и не выдаёт личности авторов или контакты.

Ошибку источника инструмент показывает как ошибку. Он не подменяет её пустой успешной выгрузкой.
